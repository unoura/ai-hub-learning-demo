# 手順2: IRISSECURITY を暗号化する

## ゴール

IRIS のセキュリティデータベース `IRISSECURITY.DAT` を暗号化し、そこに格納される認証情報・Wallet の
シークレットを**保存時(at-rest)で保護**する。これにより手順3で Wallet に入れる API キーが暗号化される。

## 方針(確定済み)

> **注意**: 参照元(`ai-hub-dev-template` / `aihub-demo`)には IRISSECURITY / DB 暗号化の実装は**存在しない**。
> 本手順は標準的な IRIS の暗号化手法に基づく**新規設計**である。

- **暗号化キー**: 暗号化キーファイルを生成する(管理キー方式)
- **起動時アクティベーション**: `IRISSECURITY` は起動の初期段階でマウントされるため、
  暗号化キーを**起動時に自動アクティベーション**する設定が必要
- **対象**: `IRISSECURITY.DAT` を暗号化(必要に応じてユーザDBも)
- **デモ用の割り切り**: 鍵ファイルとアクティベーション用パスワードは `.env` / ファイルから供給する。
  本番環境では非推奨である旨をドキュメントに明記する

## 検討事項 / リスク

- 起動時自動アクティベーションの設定方法(`.cpf` の `[Encryption]` セクション or 鍵ファイルの起動時アクティベーション設定)
- 暗号化キーファイルとパスワードの管理(コミット禁止。`.gitignore` に追加)
- ビルド時に暗号化するか、初回起動(first-boot)時に暗号化するかの選択
